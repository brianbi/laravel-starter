# 前端开发计划

> 基于 vue-pure-admin (精简版) + Vue 3 + Element Plus + TypeScript 构建

## 技术栈

| 类别 | 技术选型 | 版本 |
|------|----------|------|
| 框架 | Vue 3 | ^3.5 |
| UI库 | Element Plus | ^2.11 |
| 构建工具 | Vite | ^7.1 |
| 状态管理 | Pinia | ^3.0 |
| 路由 | Vue Router | ^4.6 |
| HTTP | Axios | ^1.12 |
| 语言 | TypeScript | ^5.9 |
| 样式 | Sass/SCSS + TailwindCSS | - |
| 图标 | @iconify/vue | ^4.2 |
| 工具库 | @pureadmin/utils | ^2.6 |
